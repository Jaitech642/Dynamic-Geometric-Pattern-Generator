# Dynamic Geometric Pattern Generator

**Overview:** Developed an event-driven Windows Forms (GUI) application in C# designed to dynamically generate and render complex spatial patterns. The application scales algorithmic output based on user-defined parameters while enforcing strict validation boundaries to maintain frontend UI integrity.

**Technical Implementations & Business Logic:**
* **Event-Driven Architecture:** Handled asynchronous user interactions (button clicks) to trigger specific rendering algorithms and update UI components in real-time.
* **Input Validation & Error Handling:** Engineered robust boundary checks to prevent application crashes from non-numerical inputs. Implemented an iteration ceiling to prevent UI overflow and trigger targeted error messaging.
* **Algorithmic Loop Structures:** Utilized nested iteration models to calculate spatial formatting, character rendering, and inverted structural layouts.
* **DRY Code Structuring:** Refactored repetitive UI-reset and validation logic into centralized helper methods, improving code maintainability and scalability.

**Tech Stack:** C#, .NET, Windows Forms, UI/UX State Management
